# 先读结构，再定骨架

简读版的骨架**由书本身决定**。这里给的是推导方法和几个已验证的原型，不是要填的表格。

## 怎么读出一本书的结构

读原书目录、序言、以及**任意三章正文**，回答四个问题：

| 问题 | 落到哪 |
|------|--------|
| 全书按什么推进？时间 / 问题 / 框架层级 / 论证步骤 / 案例序列 | `narrative`，也决定分组方式 |
| 每章内部反复出现的动作是什么？ | `chapterSections` |
| 章之上有没有分组（部、篇、时代、阶段）？ | `groups` |
| 作者最在意读者带走什么？ | 决定哪一段是主体段 |

**关键在第二问：对照三章，只有重复出现的才是骨架。** 只看一章会把偶发段落当成结构。

三条判据：

1. 段名必须能装下这本书**每一章**的内容。有一章硬填，就是骨架错了
2. 段数控制在 4–7。少于 4 撑不起结构，多于 7 会碎
3. 必须有一个明确的**主体段**，占全章一半以上篇幅。其余是入口和收口

## 结构原型

已验证的两个（A 思想史、E 文集）+ 几个可直接改用的起点。它们是候选，不是清单。

### A 思想史 / 学科史（西方哲学史 v2.0 用的就是这套）

```
## 本章定位     ← 这一章承接什么、要处理什么困难
## 关键问题     ← 5–8 条，用问句
## 理论应对     ← 主体段，沿原书编号小节展开
## 代表人物     ← 每人：生平与处境 / 核心观点 / 理论价值
## 本章小结     ← 答案是什么、代价是什么、推给下一章什么
## 主要问题     ← 可自问自答，用于回读
```

分组按**时代**，导航页讲时代之间如何互相逼出。

### B 方法论 / 实操

```
## 本章要解决的问题
## 框架与概念
## 操作步骤        ← 主体段
## 案例
## 适用边界与失效条件
## 可直接带走的动作
```

分组按**框架层级**或**使用阶段**。边界那段不能省，方法论书最容易被当万能药。

### C 论证型专著

```
## 本章论题
## 论证链          ← 主体段，一步一步保留
## 关键证据
## 作者处理的反驳
## 本章结论与遗留问题
```

分组按**论证的推进阶段**。反驳那段决定简读版有没有价值。

### D 传记 / 回忆录

```
## 本阶段处境
## 关键决策与转折   ← 主体段
## 当时的判断依据
## 后果与代价
## 可迁移的经验
```

分组按**人生阶段**。要保住"当时只知道什么"，否则全是事后诸葛。

### E 文集 / 文献汇编（毛选 v2.0 用的就是这套）

```
## 写作情境        ← 什么时间、什么场合、写给谁、针对什么倾向
## 要解决的问题
## 核心论断        ← 主体段，沿原文顺序展开
## 怎么论证的
## 后来怎么验证    ← 原文没提就写「原文未涉及后续验证」，不自己补历史
## 适用边界        ← 判断依赖的当时条件，只从原文读得出的讲
```

分组按**时间阶段**（毛选就是五卷）。这类书没有"章内固定动作"式的教材骨架，
真正反复出现的是「当时什么局面 → 作了什么判断 → 主张怎么办 → 后来应验没有」。
篇幅落差极大（毛选单篇 130 字到 4.2 万字），`chapterMinBytes` 要放低。

### F 科普 / 自然科学

```
## 本章要解释的现象
## 机制             ← 主体段
## 证据与实验
## 常见误解
## 当前的未知
```

分组按**尺度**或**认识推进顺序**。

## 写进 abridged.json

```jsonc
"narrative": "按时代正序推进；每章内部是问题—理论—人物",
"chapterSections": ["本章定位", "关键问题", "理论应对", "代表人物", "本章小结", "主要问题"],
"guideSections": ["时代定位与时间线", "本时代关键问题", "理论应对的接续",
                  "代表人物索引", "逐章阅读", "时代总结", "留给下一时代的问题"],
"kindLabels": { "chapter": "逐章正文", "guide": "时代导航" }
```

`qa-abridged.py` 按 `chapterSections` 校验，脚本里没有写死任何段名。

## 分组导航页

导航页结构同样随书而变，但四件事固定：

1. 本组的推进线索（时间线 / 层级 / 论证阶段）
2. 本组要处理的核心问题
3. 内部如何接续（按章与条目串联，**不复制正文**）
4. 条目索引 + 逐章入口（相对链接 `./章节/NN-*.md`）

6000–11000 字节。它是导航，不是第二份正文。

## 信息量判据（与书型无关）

目标：**约保留原章 50% 有效信息**。

1. 未读原书的人能读懂推理过程，而不是只记住结论
2. 相互冲突的立场，能说清各自要保住什么
3. 例子还在。删例子最省字，也最先让人读不懂

## 常犯的错（都出自首版 20 章的实测）

| 错 | 实际发生 | 后果 | 卡在哪 |
|----|----------|------|--------|
| 套用别的书的骨架 | — | 段名装不下内容，压缩时硬填 | 阶段 1 人工确认 |
| 主标题写 `##` | 8 章 | HTML 显示"未命名章节" | QA 第 1 关 |
| 整章层级下移一级 | 4 章 | 段名成了 `###`，结构失效 | QA 第 2 关 + `normalize-headings.py` |
| 段名抄进写作指令 | 10 章 | 读者看到"（沿原书小节完整展开）""list" | QA 第 2 关 + 扳正脚本 |
| 标题跳级 | 3 处 | `## 代表人物` 直跳 `#### 人名` | QA 第 3 关 + 扳正脚本 |
| 链接少写一层目录 | 3 条 | 导航页链到 `./14-*.md`，实际在 `章节/` | QA 第 5 关 + 扳正脚本 |
| 漏掉原书小节 | — | 看着完整，实则缺内容 | QA 覆盖率关 |
| 写成人物/要点卡片 | — | 变成观点集，不是简读版 | 人工抽读 |

前六类都是机械偏差，交给 `normalize-headings.py`，不要人工逐章改。
最后两类脚本查不出，必须抽读。
