# book-abridged-edition

> 把一本已经 ingest 的大部头，压成能从头读到尾的结构化简读稿 + 单文件阅读器。  
> **不是观点卡片。** 结构从书里读出来，不套模板。

这是 [book-learn-distill](../book-learn-distill/) 的并列管线：那条线做 Skill 和知识图谱（v1.0 概述），这条线做「能读完的书」（v2.0 简读版）。

---

## 安装

```bash
git clone https://github.com/muqian2026-rgb/qian-public.git
cp -r qian-public/book-abridged-edition ~/.cursor/skills/book-abridged-edition
```

口令：

```
做一版简读版
原书简读版
/abridged
```

原文须先走 book-learn-distill / docling-ingest。完整书稿留在你的私有库，本仓库只提供 Skill 源码。
