# 图书馆两级知识图谱

单书 equipped 之后，图书馆还有一层：跨书关系。  
这不是把所有节点丢进一张力导向图。

## 两级

| 级 | 文件 | 读什么 | 交互 |
|----|------|--------|------|
| 综合 | `知识图谱/1-综合知识图谱.html` | 只列跨书关系 | 按类型分组的卡片，点开看解释 |
| 单书 | `知识图谱/2-单书知识图谱/<slug>.html` | 只连该书内部 | 节点少，力导向还能看 |

综合页默认藏掉「书内概念」边。中等置信默认隐藏，打开后仍标待核。

## 跨书才连

只允许这四类，而且必须能用一句话说清：

| 类型 | 含义 |
|------|------|
| 上游 | 左边给右边提供机制或前提 |
| 互补 | 两套工具一起用更完整 |
| 同题异见 | 同一问题，结论不同，不要并成一句 |
| 边界修正 | 右边给左边划使用边界 |

没有解释依据的不连。不要用 `existingKnowledgeLinks` 自动铺满。

关系写在 `知识图谱/build_graphs.py` 的 `RELATIONS`。改数据或加边之后：

```bash
python3 知识图谱/build_graphs.py
```

脚本只写 `知识图谱/`，不改各书原文。

## 目录怎么排

网站「知识图谱」tab：

1. **总览单独一级**：综合图谱横贯一行  
2. **下面三列并排**：方法论 / 经典 / 学科，各放单书图谱  

v1.0 概述、v2.0 简读本来就是这三列，不要把综合图谱塞成第四列。

## 何时跑

- 一本新书标 `equipped` 之后  
- 改了某书 `06-graph-data.json` 且综合页用到了它的节点  
- 新增或核对一条跨书关系  

公开库只带这条规则，不带书目全文。完整产出在你的私有图书馆目录。
