# book-abridged-edition

> 把一本已经 ingest 的大部头，压成**能从头读到尾**的结构化简读稿 + 单文件阅读器。  
> 输入：原书正文  输出：按原书顺序的简读版，不是观点卡片。

这是 [book-learn-distill](../book-learn-distill/) 的并列管线。

| | v1.0 `book-learn-distill` | v2.0 `book-abridged-edition` |
|---|---|---|
| 解决什么 | 读完以后能**调用**：口令、框架、知识图谱 | 读的时候能**读完**：论证还在，篇幅能坐下 |
| 像什么 | 地图 + 工具箱 | 精简过的原书 |
| 不够的时候 | 有框架，仍不知道作者是怎么推到这一句的 | 有正文，但不替代 Skill 调用 |

两条都要。只有 v1，会以为自己懂了，其实只记住了标签。只有 v2，读完仍没法在别的问题上调用。

## 设计思路

### 问题从哪来

大部头读不完，是真的。斯通普夫《西方哲学史》原文 160 万字节、20 章；毛选更长。常见三条出路都不成立：

1. **只做要义课**（2–3 小时）——能讲清主句，带不走论证。没读过的人听完会点头，碰到原书里的反例就穿帮。
2. **只做知识图谱 / Skill**——适合定位和调用，不适合「顺着作者把一章走完」。图谱上的节点是结论，不是推演。
3. **让模型「总结一下这本书」**——它会换成自己的知识，补进原书没有的事实，再按「背景 / 要点 / 启示」重排。看起来像读过，其实是另一本书。

这条管线要的是第四条：**原书的精简**。删重复表述和枝节，保留论证链、概念差异、人物关系和必要例子。未读原书的人应能读懂作者怎么推，而不是只认识人名。

默认保留约一半有效信息。判据不是字数减半，而是：段还在、例子还在、限制条件还在。压成提纲，算失败。

### 两条铁律（都是翻车以后立的）

**一、结构从书里读出来，不套模板。**

哲学史按「时代 → 问题 → 理论 → 人物」走。方法论书按「问题 → 框架 → 步骤 → 案例」走。论证型专著按「论题 → 论证 → 反驳 → 结论」走。拿哲学史的骨架去套一本方法论，段名对不上内容，压缩时只能硬填——表面整齐，书已经被拆坏。

所以第一阶段先摸**这一本**的叙述逻辑，写进 `abridged.json` 的 `chapterSections`。后面的并行任务和验收脚本都以它为准。**脚本里没有写死任何段名。**

**二、先机械拆章，再逐章压缩。**

把整本书交给一个任务「按时代整理」，会静默失败：不报错、不写文件，只是卡住。西方哲学史第一次按五个时代切五个并行任务，全部空转。改成先切 20 个章文件、再一章一压，一次通过。

拆分是机械动作，必须用脚本，不能让模型「读一遍再分」。并行粒度按源文字数切，不按篇数切：一个任务大约一万汉字、最多两章。提示越短越不容易跑飞。

### 为什么要有阅读器，而不停在 Markdown

Markdown 是生产格式，不是阅读格式。成品是单文件 HTML：目录、搜索、进度、标注、章节勾选、读书笔记导出。人是在这里读完的，Agent 不代写个人批注。

标注是语义的，不是荧光笔：黄=重点，蓝=概念/观点，红=疑问/不同意，绿=启发/关联。读完后导出的笔记，才能接回 v1 的 Skill 和图谱。

### 门禁为什么这么硬

11 项验收每一项都对应一次真实返工。典型的有：

- 主标题写成二级，阅读器目录全是「未命名章节」
- 段名夹带写作指令（「理论应对（沿原书小节完整展开）」），骨架对不上
- 只改了正文、忘了重编译目录
- 把「人同上帝的关系」误判成占位词「同上」——门禁一开始误报，就会被当噪音关掉

所以验收只收纯占位词，段名必须与骨架**逐字一致**，改了标题必须重新编译。绿了才能定稿。

### 明确不做什么

- 不引入原书没有的事实与判断，不用模型自身知识替换原文
- 不改动 `原文/`、知识图谱和 v1 Skill
- 不把简读版当产品框架、组织管理或当代学术拍板
- 原文还没 ingest，先走 v1 / docling，不从这条线起跑

## 七阶段

| 阶段 | 做什么 | 卡住什么 |
|------|--------|----------|
| 0 定版 | 版本号、保留比例 | 信息量预期 |
| 1 读结构 | 摸清原书自己怎么推进 | **骨架**（最不该省） |
| 2 拆章 | 脚本机械切分 | 章数与原书目录一致 |
| 3 压缩 | 按骨架逐章写 | 段名齐全，不是提纲 |
| 3.5 扳正 | 标题层级与段名归一 | 先预演再改 |
| 4–5 导航与收口 | 分组导航 + 导读 + 全书总结 | 只导航，不复制正文 |
| 6 成品 | 编成单文件阅读器 | 占位符全部替换 |
| 7 验收 | 11 项硬门禁 | 全绿才定稿 |

人要确认的主要是阶段 1：骨架一旦开压，20 章返工的代价远大于先聊清楚。

细节、命令和字段见 [SKILL.md](./SKILL.md)、[references/pipeline.md](./references/pipeline.md)。

## 安装

```bash
git clone https://github.com/muqian2026-rgb/qian-public.git
cp -r qian-public/book-abridged-edition ~/.cursor/skills/book-abridged-edition
```

口令：

```
做一版简读版
原书简读版
/abridged
```

完整书稿留在你的私有库。本仓库只提供 Skill 源码，不发布书摘全文。
